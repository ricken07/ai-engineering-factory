# 11 — Task Lifecycle

Reference lifecycle:

```text
Task intake
  ↓
Understand
  ↓
Resolve context
  ↓
Impact analysis
  ↓
Risk assessment
  ↓
Policy decision
  ↓
Plan
  ↓
Gate (if required)
  ↓
Implement
  ↓
Validate
  ↓
Review
  ↓
Trace
  ↓
Submit
  ↓
Human/CI gates
  ↓
Merge or handoff
```

A task may span multiple repositories while remaining one functional task. Each repository may have independent branches, commits and change requests linked back to the same task/execution.
