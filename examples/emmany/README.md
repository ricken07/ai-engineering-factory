# Emmany — Poly-repository Example

This example demonstrates how a project workspace may contain multiple independent Git repositories while using one project-level Factory context.

```text
emmany/
├── .ai/
├── AGENTS.md
├── CLAUDE.md
├── egw-api/   # independent Git repository in a real checkout
└── egw-app/   # independent Git repository in a real checkout
```

The example directories are placeholders only; they are not nested Git repositories in this package.
